# 🌱 Gestão de Custos da Engorda

Sistema web desenvolvido para auxiliar no controle e gerenciamento dos custos relacionados à engorda de animais.

## 📌 Sobre o projeto

O **Gestão de Custos da Engorda** é uma aplicação web desenvolvida com o objetivo de facilitar o cadastro, organização e gerenciamento de insumos utilizados durante o processo de engorda.

A aplicação permite registrar informações como nome do insumo, quantidade e unidade de medida, além de possibilitar a edição e exclusão dos registros cadastrados.

O projeto foi desenvolvido como parte das atividades do curso Técnico em Informática, utilizando tecnologias voltadas para desenvolvimento web e banco de dados.

## 🚀 Funcionalidades

- ✅ Cadastro de insumos
- 📋 Visualização dos insumos cadastrados
- ✏️ Edição de informações
- 🗑️ Exclusão de registros
- 💾 Armazenamento dos dados em banco SQLite
- 🌐 Interface web simples e intuitiva
- ⚠️ Validação dos campos de cadastro
- 🔢 Validação da quantidade informada

## 🛠️ Tecnologias utilizadas

- **Python**
- **Flask**
- **HTML5**
- **CSS3**
- **SQLite**
- **Git e GitHub**

# Gestão de Custos da Engorda

Sistema para cálculo dos custos relacionados à engorda de animais.

## Cálculo do custo por quilograma

O sistema calcula automaticamente o custo por quilograma produzido.

### Fórmula

Custo por kg = Custo total ÷ Ganho de peso

Ganho de peso = Peso final − Peso inicial

### Exemplo

- Custo total: R$ 1.500,00
- Peso inicial: 300 kg
- Peso final: 450 kg
- Ganho de peso: 150 kg
- Custo por kg: R$ 10,00
