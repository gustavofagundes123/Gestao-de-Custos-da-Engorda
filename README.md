# Gestão de Custos da Engorda

## Descrição

O **Gestão de Custos da Engorda** é um sistema desenvolvido para auxiliar no controle e gerenciamento dos custos relacionados à alimentação de animais durante o processo de engorda.

O projeto tem como objetivo facilitar o **cadastro, organização e cálculo dos custos de alimentação**, permitindo registrar informações dos alimentos utilizados e seus respectivos valores. Dessa forma, o sistema contribui para uma melhor visualização dos gastos e para o acompanhamento dos custos envolvidos na produção.

O sistema está sendo desenvolvido utilizando **Python, Flask, HTML, CSS e banco de dados**, seguindo uma estrutura organizada para facilitar a manutenção e a evolução do projeto.

## Objetivos

* Cadastrar os custos relacionados à alimentação;
* Organizar as informações dos alimentos utilizados;
* Realizar cálculos dos custos de alimentação;
* Facilitar o acompanhamento dos gastos durante a engorda;
* Proporcionar uma interface simples e prática para o usuário.

## Funcionalidades

* Cadastro de custos de alimentação;
* Armazenamento das informações no banco de dados;
* Consulta e organização dos dados cadastrados;
* Cálculo dos custos;
* Interface web para interação com o sistema.

## Tecnologias utilizadas

* **Python**
* **Flask**
* **HTML5**
* **CSS3**
* **Banco de dados**
* **Git e GitHub** para controle de versão
